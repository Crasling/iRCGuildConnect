================================================================================
iRacelockConnection - Changelog
================================================================================

v0.2.6 -
--------------------------------------------------------------------------------
 [CHANGED] Renamed Total players to Total members in Guild Statistics
 [CHANGED] Active players now shows each guild's highest observed online-member count during the last 24 hours
 [FIX] Presence warnings now require a full 60-second confirmation window and three fresh probes before being sent
 [NEW] Guild Found now protects incoming mail and blocks collecting external-player or Auction House items and money
 [FIX] Guild Found mail restrictions now guard the underlying mail APIs so other addons cannot bypass the send or collection checks
 [FIX] Guild Found now guards AcceptTrade directly, closing the short verification window in which an external trade could otherwise be accepted
 [FIX] Guild activation requests now receive a direct activation, ruleset and presence handshake so newly installed clients cannot remain stuck as ForkEU-compatible only


v0.2.5 - Guild Statistics & Economy Enforcement
--------------------------------------------------------------------------------

 [CHANGED] Reworked Guild Statistics to discover guild names through iRC and group them dynamically under Horde and Alliance
 [CHANGED] Guild rankings now sort by level-60 members, active players, then total roster size
 [NEW] Guild Masters can choose the character level at which the same-race group rule begins
 [NEW] Added an optional Guild groups only rule with its own configurable starting level
 [CHANGED] The former achievement panel is now the main iRC window, opening on Guild Statistics with achievements as a secondary section
 [CHANGED] RP achievement providers are now race-specific; TrollFound integration is active only for Troll characters
 [CHANGED] Test administrator access now supports both Crasling-Soulseeker and Crasjin-Soulseeker
 [CHANGED] Temporarily hid the Achievement navigation section while retaining its implementation for later work
 [NEW] Test administrators can suppress all automatic presence warning messages while using fake Guild Master mode
 [CHANGED] Guild Statistics now uses full-width guild cards with a larger, outlined class-distribution bar
 [NEW] Added race-locked Tauren Talk with conservative word and short-phrase substitutions designed to keep chat readable
 [CHANGED] Guild Statistics cache is now account-wide per server and remains display-only; outgoing reports always use current live guild data
 [FIX] Leveling up or reloading while grouped can no longer trigger an automatic leave; new restrictions begin after the current group ends
 [CHANGED] Guild Found no longer applies party or raid restrictions; all group enforcement is configured exclusively under Group Rules
 [CHANGED] Moved Guild Found verification to a dedicated options tab visible only to Guild Masters and rank-1 officers
 [CHANGED] Guild Statistics cards are compact by default and expand on click to show the guild's active iRC rules
 [CHANGED] Guild Statistics class breakdown now counts only characters at level 19 or higher
 [CHANGED] Each Class Breakdown percentage is now centered above its matching class bar segment
 [FIX] Live iRC profiles now take priority over RaceLocked data, while a newer compatible-addon response cleanly replaces an expired iRC profile
 [FIX] Recreated characters receive a fresh addon check instead of inheriting cached verification or warnings from a deleted character with the same name
 [FIX] Race Overview no longer processes the local player's own global requests and reports as incoming data

v0.2.4 - Guild Activation, Verification & Compatibility
--------------------------------------------------------------------------------

 [NEW] Guild Masters must explicitly enable iRC for each guild before sharing, verification, compatibility data, or guild rules start
 [NEW] Guild Masters can set a shared guild race, defaulting to the Guild Master's own race when iRC is activated
 [NEW] Added Guild Found status, Guild Master review controls, gold-discrepancy checks, guild-death tracking and level-60 statistics
 [NEW] Added optional RaceLocked and RaceLockedForkEU compatibility for shared roster, rule and Race Overview data
 [NEW] Added manual Race Overview sharing and refresh controls when global sharing is enabled
 [CHANGED] HardcoreAchievements and TrollFound are optional; iRC loads normally without either addon
 [CHANGED] Achievement points are temporarily excluded from Race Overview, Verification, Champions and Leaderboard while statistics are reworked
 [CHANGED] Active Verification filters now use the same orange glow style as iWR
 [FIX] Missing-addon warnings now wait for confirmation and a login grace period, reducing false warnings after login or reload
 [FIX] Reduced duplicate startup sync messages and delayed hidden data-channel joins until normal chat channels have loaded
 [FIX] Presence notifications automatically move to another eligible online officer when the current notifier leaves
 [FIX] Race Overview now uses the correct fixed guilds and counts verified and compatible members once, including known offline members
 [FIX] Improved dashboard performance for large guild rosters
 [FIX] Fixed options and minimap settings errors that could prevent the settings window from opening
