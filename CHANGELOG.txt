================================================================================
iRacelockConnection - Changelog
================================================================================

v0.2.14 - Safer Group Enforcement
--------------------------------------------------------------------------------
 [FIX] Existing groups are safely preserved when group rules begin applying through level-up, reload, or login
 [FIX] Automatic group leaving now requires a second confirmed group check after a safety delay
 [NEW] Five-minute addon warnings are saved in the officer incident history
 [NEW] Rank 0 and rank 1 can optionally enable shared new-member welcome messages, disabled by default


v0.2.13 - Guild Cache Sharing & Race Verification
--------------------------------------------------------------------------------
 [CHANGED] Refresh / Share now uses the working guild-cache request instead of sending a global request that Classic clients cannot answer automatically
 [FIX] Race Talk no longer taints protected slash commands such as /gquit
 [NEW] Guild members can exchange validated recent Guild Statistics snapshots so online members help fill missing guild data without publishing cached reports globally
 [NEW] Guild Verification flags members whose known character race does not match the guild's configured race


v0.2.12 - Guild Found Management & Statistics Fixes
--------------------------------------------------------------------------------
 [FIX] Receiving another guild's statistics no longer starts or resets the local Refresh / Share cooldown
 [FIX] Guild Statistics now accepts valid reports when WoW includes the sender's realm in the channel name
 [FIX] Guild Master verification decisions now update a level 60 member's displayed Guild Found and gold status while addon presence remains independently verified
 [CHANGED] Guild Found tools are grouped under a dedicated Management category in the options panel
 [CHANGED] The Level 60 Guild Found description now explains its gold-status and item-transaction monitoring
 [CHANGED] Guild Statistics cards are shorter and no longer display guild deaths


v0.2.11 - Guild Found Security & Audit
--------------------------------------------------------------------------------
 [CHANGED] Guild Statistics refresh now uses a five-minute shared cooldown to prevent repeated channel traffic
 [FIX] Relayed guild rules must match the last ruleset received from guild leadership before another member can share them
 [NEW] Rank 0 and rank 1 members can review level 60 Guild Found economy audit and reported restriction events
 [FIX] Level 60 Guild Found protection remains active from the verified guild backup and cannot be disabled by changing only one local ruleset value
 [NEW] Ruleset senders and receivers now confirm that identical timestamps contain identical rule data


v0.2.10 - Guild Found Verification
--------------------------------------------------------------------------------
 [NEW] Officers can right-click members in Verification to review Self-Found and Guild Found reports, contact them or request fresh addon data
 [NEW] Guild Masters can record Guild Found decisions for level 60 members directly from the Verification member menu
 [CHANGED] Guild Found management now lives entirely in the Connection panel with a clearer grouped menu and compact reports
 [CHANGED] RaceLocked compatibility now covers only current addon presence and Self-Found status
 [FIX] Missing or expired addon responses always show Not verified; manual Guild Master decisions cannot replace reported status
 [CHANGED] Removed HardcoreAchievements and TrollFound integration; iRC now uses only its own data
 [CHANGED] LibDBIcon is bundled inside iRC and no longer treated as an external dependency
 [CHANGED] Removed the achievement system, scores and points so iRC focuses entirely on guild rules, verification, members and statistics
 [CHANGED] Verification now labels Self-Found, Guild-Found or general addon verification according to the guild's active rules and level exceptions
 [CHANGED] Guild reports older than five days are automatically removed from Guild Statistics
 [FIX] Opening the main iRC window through slash commands or member inspection now triggers the same Guild Statistics refresh as the minimap and options buttons
 [FIX] Guild Statistics reports now use Classic-compatible custom-channel messages and safely split reports that exceed the chat-message limit
 [CHANGED] Debug mode now shows the send and receive progress of split Guild Statistics report packages
 [FIX] Incomplete public report packages now expire safely and cannot grow the receive cache without limit
 [FIX] RaceLockedForkEU presence remains compatible after the cleanup and is identified by its correct source in verification


v0.2.9 - Performance
--------------------------------------------------------------------------------
 [FIX] Guild Members now creates only the visible list rows, preventing script timeout errors in large guilds
 [CHANGED] Guild Verification columns are aligned more clearly and its filter buttons now use the modern iRC active-state styling
 [NEW] The Needs attention filter now pulses when one or more guild members require review
 [NEW] Test administrators can optionally display the settings pages normally reserved for guild rank 0 and rank 1
 [CHANGED] Removed Champions and Leaderboard from the Connection window so it stays focused on guild verification
 [NEW] Guild Masters, rank-1 officers and test Guild Masters can right-click Verification members to send addon guidance or request fresh iRC data
 [FIX] Verification member management now uses a native iRC context panel so right-click works reliably on Classic clients
 [CHANGED] Removed the redundant Faction column from the Verification Overview table
 [CHANGED] Guild Member rows no longer perform any action on left-click while that list is awaiting its rework
 [FIX] Verification Overview now uses a full-width four-column layout with readable headings and more space for the class summary
 [FIX] Sort indicators now use Classic-compatible arrow characters instead of unsupported square glyphs
 [CHANGED] Removed the race filter buttons from Verification Overview, which now always displays every represented race


v0.2.8 - Options Cleanup
--------------------------------------------------------------------------------
 [CHANGED] Temporarily hidden the Guild Found Verification tab from the settings menu
 [FIX] Invalid groups are never left automatically during combat, inside an instance, while dead, or on a taxi; iRC warns first and waits for a safe open-world moment
 [NEW] Restricted-group incidents are saved with time, location and involved players, then reliably reported once to the active officer client after combat
 [NEW] Automatic group leaving now displays a clear local iRC message in addition to the party or raid explanation
 [FIX] Test Guild Master mode no longer replaces a real officer as the notification sender; officer alerts are always handled by an actual rank 0 or rank 1 member
 [FIX] Guild Members now checks the current guild roster when opened, removes departed characters and shows their current roster levels
 [CHANGED] Public race-grid sharing is now always enabled and its optional setting has been removed
 [CHANGED] Achievement notifications are now disabled while achievements are being reworked, and their display setting has been removed
 [NEW] iRC now notifies you when another guild or Public Grid client reports a newer addon version
 [FIX] Every blocked trade, mail collection, Auction House visit or automatic group action now gives the player a local iRC explanation
 [NEW] Guild rules now synchronize through the highest available iRC guild rank (0, then 1, then 2 and onward), allowing new members to receive the active rules even while higher ranks are offline
 [NEW] Relayed guild rules now retain their GM-created hexadecimal timestamp and source, preventing an older relay from replacing newer rules
 [NEW] Rank 0 and rank 1 officers now have an Incidents view under Verification; rank 1 hands saved reports to the GM when the rank 0 iRC client returns
 [FIX] Test warning suppression now stops presence checks silently, and officer eligibility text no longer implies that test-GM grants officerchat authority
 [CHANGED] Guild Verification now shows Self-Found activity before level 60, Guild Found verification at level 60, and Clean status in its own column


v0.2.7 - Guild Sharing & Reliable Verification
--------------------------------------------------------------------------------
 [FIX] Reduced false addon warnings by checking once more for a recent response before notifying players and officers
 [CHANGED] RaceLockedForkEU status now expires after 135 seconds when no new response is received
 [NEW] Guild Masters can add invite contacts to their guild's expandable Statistics card
 [CHANGED] Guild Statistics are now shared only between iRC users and no longer sent through other addons' data channels
 [FIX] Refresh / Share now sends guild information more reliably, including reports from large guilds
 [NEW] Enabling global sharing or opening the main iRC window now shares fresh guild information when available
 [CHANGED] Refresh / Share displays a 30-second cooldown after sharing or receiving new guild information


v0.2.6 - Reliable Guild Verification & Guild Found Economy
--------------------------------------------------------------------------------
 [CHANGED] Renamed Total players to Total members in Guild Statistics
 [CHANGED] Active players now shows each guild's highest observed online-member count during the last 24 hours
 [FIX] Presence warnings now require a full 60-second confirmation window and three fresh probes before being sent
 [NEW] Guild Found now protects incoming mail and blocks collecting external-player or Auction House items and money
 [FIX] Guild Found mail restrictions now guard the underlying mail APIs so other addons cannot bypass the send or collection checks
 [FIX] Guild Found now guards AcceptTrade directly, closing the short verification window in which an external trade could otherwise be accepted
 [FIX] Guild activation requests now receive a direct activation, ruleset and presence handshake so newly installed clients cannot remain stuck as ForkEU-compatible only
